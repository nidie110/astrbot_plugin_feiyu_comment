# astrbot_plugin_feiyu_comment

> 让她先写好，你点头，她才发出去。

给 AstrBot 里的拟人插件加一层「说不说话由你决定」的闸门：她自己不能发评论，只能写草稿；只有你回一句「发」，插件才用**你已经登录的 B 站账号**把那条评论发出去。

## 为什么是这样设计的

让一个 AI 用你的实名牌去公开评论，风险全在你这边：说错话、说过头、被风控、事后难撤。所以这里的默认姿态是——

- **她能写，不能发。** 工具只负责存草稿，发布动作只听**账号主人**的「发」。
- **不走密码。** 不做账号密码登录、不碰验证码，直接借用浏览器里已经登录的那个会话（同源 `fetch` + `bili_jct`）。
- **只有主人能点头。** 点头指令校验 `event.is_admin()` 或 `owner_ids`；机器人自己发的消息永远不算点头，别人在群里说「发」也不会动。
- **批准的就是你看到的那条。** 草稿按会话隔离、同一会话只留最新一条，回执里带 id 和原文。
- **每条都过手。** 草稿有时效（默认 2 小时），过期作废，防止几天后翻出一条老草稿突然发出去。
- **发过就不重发。** 状态机 `pending → posting → (已发 | 不确定)`；超时或读不到回执时标记「不确定」，只提醒你去核对，不会自己再发一遍。
- **有刹车。** 每日条数、最小间隔、字数上限都在配置里。

## 怎么用

1. 你在群里把 B 站视频链接发给她，说「你回他一句」。
2. 她调 `prepare_comment` 写草稿，然后把**原文和目标链接**贴给你看。
3. 你回：

| 你说 | 会发生什么 |
| --- | --- |
| `发` / `发吧` / `可以发` | 真的发出去，回执里带 rpid |
| `改：再短一点点` | 把草稿改成新内容，再问你一次 |
| `算了` / `别发` | 作废，什么都不发 |

也可以用指令：

- `/草稿` 看待发队列
- `/废` 作废最新那条
- `/发 [id]` 直接发（不给 id 就发最新的）
- `/发评论` 看帮助

## 配置

| 键 | 默认 | 作用 |
| --- | --- | --- |
| `enable` | true | 总开关，关掉连草稿都不存 |
| `dry_run` | false | 只回显不真发，第一次装建议先开着试 |
| `owner_ids` | `""` | 谁的点头算数（QQ 号，逗号分隔）；留空 = AstrBot 管理员 |
| `bsk_path` | `""` | bsk 可执行文件，留空自动找 |
| `bsk_browser` | `""` | 用哪个浏览器实例，留空取第一个 |
| `max_chars` | 180 | 评论字数上限 |
| `ttl_minutes` | 120 | 草稿有效期（分钟） |
| `daily_limit` | 5 | 每天最多发几条 |
| `min_gap_seconds` | 30 | 两条之间最少间隔 |

## 依赖

- 装了 [bsk](https://github.com/) 的环境，并且浏览器里**已经登录 B 站**
- 只能跑在 Windows（用了 `CREATE_NO_WINDOW` 与 bsk 的本地 daemon 模式）

## 边界与已知限制

- 目前只接 B 站（`bilibili.com` / `b23.tv` / `bili2233.cn`），其他站点直接拒绝。
- 只支持 B 站**视频**评论区（`type=1`，oid 取页面 `__INITIAL_STATE__.aid`）；动态、专栏、番剧还没接，传了会明确说 no-aid。
- 白名单只放行 `bilibili.com` / `b23.tv` / `bili2233.cn`（点边界匹配，`evilbilibili.com` 之类拒）；发布前会比对页面最终 BV 与草稿一致，跳转到别的视频就中止。
- 发布走页面同源 `fetch`，不是点页面按钮——因为无头会话里评论组件常只渲染转圈，取不到编辑器。
- 被风控（`-412`）、评论区关闭（`12002`）、登录失效（`-101`）会如实回报，不会重试堆请求。
- 发表即公开，撤回要你自己去 B 站删；插件不做删除。在途请求也撤不回——按「算了」时若已经在发，会如实告诉你。
- 配额按「尝试」算（失败也算），反复失败不会无限撞 B 站。
